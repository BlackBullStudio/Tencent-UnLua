# 빠른 시작 예제

본 문서는 UE 초보자 관점에서 Actor를 부모 클래스로 하는 사용 사례를 통해 Lua로 블루프린트 로직을 작성/오버라이드하는 방법을 설명합니다. 다른 타입도 이와 같은 방식으로 유추할 수 있습니다.

이미 UE의 숙련자라면 [UnLua 여행 시작하기](../../README.md#开始UnLua之旅)를 직접 참조하는 것을 권장합니다.

## 1. 새 블루프린트 생성
![새 블루프린트 생성1](../Images/create_new_actor_bp_1.png)
![새 블루프린트 생성2](../Images/create_new_actor_bp_2.png)

## 2. Lua에 바인딩
- 이전 단계에서 생성한 블루프린트를 더블클릭하여 열고, UnLua 메뉴 바의 "바인딩"을 클릭하면 기본적으로 블루프린트 경로에 따라 Lua 모듈 경로가 자동으로 채워집니다(그림의 ①과 같이).
- 다음에 바인딩 경로를 수정해야 한다면 `GetModuleName` 함수를 찾아 더블클릭하여 수정할 수 있습니다(그림의 ②와 같이).
- 완료 후 "컴파일"과 "저장"을 잊지 마세요(그림의 ③과 같이).

![Lua 바인딩1](../Images/bind_to_lua_1.png)
![Lua 바인딩2](../Images/bind_to_lua_2.png)

## 3. Lua 템플릿 코드 생성
UnLua 메뉴 바의 "Lua 템플릿 파일 생성"을 클릭하면 프로젝트 `Content/Script` 디렉토리에 생성됩니다.

![템플릿 코드 생성](../Images/generate_lua_template.png)

##  4. 준비 완료

![파일 관리자에서 표시](../Images/reveal_in_explorer.png)

마지막으로, 좋아하는 에디터로 생성된 파일을 열어 코드 작성을 시작하세요.

**주의**: 엔진의 콘텐츠 브라우저에서는 디렉토리의 Lua 스크립트를 볼 수 없으므로, 시스템의 파일 브라우저를 사용하여 확인하세요. `Content/Script`를 IDE 프로젝트에 추가하는 것을 권장하므로 매번 수동으로 탐색할 필요가 없습니다.
