# 콘솔 명령어

## 개요

게임 실행 중에 특정 객체의 메서드 호출, 속성 수정 등의 디버그 명령어를 직접 실행하여 게임 환경 디버깅에 편의를 제공할 수 있습니다.

기본적으로 `~` 키를 눌러 엔진 내장 명령어 콘솔을 호출할 수 있으며, UnLua는 몇 가지 기본 명령어를 제공합니다. 좋은 아이디어가 있다면 `UnLuaConsoleCommands`의 구현을 참조하여 확장할 수 있습니다.

## 명령어 목록

### lua.do \<code\>

기본 환경에서 Lua 코드를 실행합니다.

예시:
```
lua.do print("hello world")
```

### lua.dofile \<module path\>

기본 환경에서 지정된 Lua 파일을 실행합니다.

예시:
```
lua.do test1.test2
```

### lua.gc

기본 환경에서 강제로 가비지 컬렉션을 한 번 실행합니다.
