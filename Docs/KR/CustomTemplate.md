# Lua 템플릿 생성

타입을 Lua에 바인딩한 후, `UnLua 툴바 -> Lua 템플릿 파일 생성`을 통해 바인딩된 경로에 해당하는 Lua 파일을 빠르게 생성할 수 있습니다.

기본적으로 타입 이름에 따라 `UnLua/Config/LuaTemplates` 디렉토리에서 템플릿 파일을 찾으며, 파일이 존재하지 않으면 부모 클래스 이름으로 계속 찾습니다.

## 사용자 정의

필요에 따라 `프로젝트 디렉토리/Config/LuaTemplates` 디렉토리에 템플릿 파일을 생성하면, 생성 시 우선적으로 사용됩니다.

파일 인코딩은 UTF-8(No BOM)이어야 함에 주의하세요.
